# Plan: clouds-rp2350 — Mutable Instruments Clouds on RP2350 (2026-10-31)

## Goal

Port the full **Clouds** granular processor (all four playback modes: granular,
stretch/WSOLA, looping delay, spectral) to the RP2350 nano + PCM5102A hardware,
as a **permanent** second project (`clouds-rp2350/`) using the proven
elements-rp2350 architecture. Designed from day one to be combinable with the
other module ports (RINGS/PLAITS/ELEMENTS out → Clouds in) — the hardware has
no audio input jack, so in multi-module builds Clouds' input is the upstream
module's block FIFO; standalone it is fed by a MIDI-triggered test exciter.

## Hard requirements (user-stated)

1. Same approach as elements-rp2350: generated libs via `tools/sync_pio_libs.sh`
   (upstream `CLOUDS/` copy with `.cc` stripped, `*_all.cpp` wrappers,
   per-library `-O3`), port deltas ONLY as `tools/patches/clouds/*.patch`,
   never hand-edited `lib/`.
2. **Every LUT and all hot code in SRAM** (`.time_critical`) — XIP flash
   execution was the Elements audio-budget killer; Clouds carries ~60-80 KB of
   LUTs (`lut_sin`, `lut_window`, `lut_sine_window_4096`, SRC filters, `lut_db`).
3. Same hardware/wiring as elements-rp2350: PCM5102A (BCK GP6, DIN GP8, LRCK
   GP7), USB-C device (CDC + USB-MIDI), PIO-USB host on GP14/15, WS2812 GP22,
   240 MHz, core 0 = USB/MIDI/LED, core 1 = audio render.

## Integration surface (recon results, all read from CLOUDS/src)

- `clouds::GranularProcessor`:
  `Init(void* large, size_t large_size, void* small, size_t small_size)`.
  Mirrors the F405 two-region split. In `Prepare()`: stereo 16-bit uses
  `small_size` for BOTH channels (original small = 64 KB → 32768 samples/ch =
  1.02 s @ 32 kHz); `large` holds mono/low-fidelity sample memory and the FX
  workspace (diffuser 2048 floats, reverb 16384 uint16, correlator/WSOLA).
- `set_sample_rate(32000)` (vb's settable rate; internal `kDownsamplingFactor=2`
  SRC handles low-fidelity 16 kHz grain rendering).
- `Process(FloatFrame*, FloatFrame*, size)` with `kMaxBlockSize = 32` — render
  block = 32 samples = 1 ms @ 32 kHz (report budget becomes 1000 µs).
- Parameters (`mutable_parameters()`): position, size, pitch, density, texture,
  dry_wet, stereo_spread, feedback, reverb, freeze, trigger, gate. Playback
  modes 0-3, quality 0-3 (`set_quality`: bit0 = mono/8-bit path, bit1 =
  low-fidelity/µ-law).
- Buffers: **large = 128 KB, small = 64 KB** (same durations as the original
  hardware). STFT in spectral mode uses the sample buffers as FFT workspace
  (ShyFFT) — no extra big arrays; `lut_sine_window_4096` is the window.

## Tasks

### C1 — Scaffolding
- Generalize `tools/sync_pio_libs.sh`: project-argument form
  (`sync_project <dir> "SRC:dst" ...`), elements behavior byte-identical,
  add `clouds-rp2350 "STMLIB:stmlib" "CLOUDS:clouds"`. Patches stay
  per-lib (`tools/patches/<dst>/*.patch`), strict `--fuzz=0`.
- `clouds-rp2350/`: platformio.ini (rpipico2, 240 MHz, -DUSE_TINYUSB),
  src/ = adapted copies of elements' main.cpp/midi.h/status_led.h/
  usb_host_watchdog.c/ws2812.pio. Stub render → build SUCCESS.

### C2 — Audio bring-up
- GranularProcessor + 128/64 KB buffers + core-1 render loop (32-sample
  blocks), 2 s report with `budget 1000 us`.
- **Test exciter** in main.cpp (standalone input source; replaced by block FIFO
  in future multi-module builds): MIDI note-on = decaying pluck burst
  (filtered noise/sine), plus a drone option — enough material for grains.
- Ear check #1: grains audible, freeze holds.

### C3 — MIDI integration + README
- CC map (src/midi.h): 14 POSITION, 15 SIZE, 16 PITCH, 17 DENSITY, 18 TEXTURE,
  19 DRY/WET, 20 STEREO SPREAD, 21 FEEDBACK, 22 REVERB, 23 PLAYBACK MODE
  (0-3), 24 QUALITY (0-3), 65 FREEZE (≥64 on, <64 off), 66 TRIGGER (≥64 =
  trigger pulse), note stack → pitch + gate. USB device + PIO-USB host both.
- README (wiring reused, CC table, build/flash, diagnostics format).

### C4 — SRAM treatment (patches only)
- `tools/patches/clouds/*.patch`: clouds-local `ram_code.h`
  (`ELEMENTS_RAM_CODE(token)`-style, unique tokens), mark:
  GranularProcessor::Process/ProcessGranular/Prepare, GranularSamplePlayer,
  LoopingSamplePlayer, WSOLASamplePlayer, PitchShifter, Diffuser, Reverb,
  Correlator, SRC hot loops, and **every resources.cc LUT**.
- Verify: nm shows hot symbols at 0x2000xxxx; round-trip through sync script
  reproduces the build.

### C5 — Hardware acceptance
- Flash (button-BOOTSEL = reliable path), serial numbers vs budget, user ear
  check (grains, freeze, mode switching), 30 min soak, ledger + commit.

## Acceptance criteria

- Build reproducible from submodules + patches alone (round-trip test).
- `max Process` comfortably under the 1000 µs block budget in granular mode;
  spectral mode measured too (dropped if over budget and pvoc can't fit —
  granular/stretch/loop are the core product).
- User-confirmed audio; no stalls over a 30 min soak.
