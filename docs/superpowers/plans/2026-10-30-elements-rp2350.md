# Elements hardware clone on RP2350 + PCM5102A — Implementation Plan

- Date: 2026-10-30
- Status: approved
- Execution method: superpowers **subagent-driven development** — one fresh implementer subagent per task, reviewer checks acceptance criteria, fix loop (max 2 iterations), commit per task, progress ledger updated after each task.
- Ledger: `.superpowers/sdd/progress.md`
- Repo: `schrab/mi-rp2350` (fork of poetaster/arduinoMI). Work happens on a branch, merged to main when the user is happy.

## Goal

Standalone Mutable Instruments Elements synth voice on an RP2350 "nano" board (serial port `/dev/ttyACM0`) with a PCM5102A I2S DAC. Synth mode only — no audio input. MIDI enters from two sources simultaneously:

- **USB device** (native USB-C port): PC/DAW.
- **USB host** (PIO-USB on GP14/GP15 + passive USB-A socket): hardware MIDI controller. No extra chips.

Build system: **PlatformIO** (pio available via mise shim) with the earlephilhower arduino-pico core.

## Non-goals for phase 1

No CV jacks, no panel pots/buttons/OLED, no preset system, no DIN MIDI. (Follow-up phase T7.)

## Architecture

- **Core 0** (`setup()`/`loop()`): USB device stack (TinyUSB MIDI device), USB host stack (PIO-USB + TinyUSB host MIDI), MIDI parsing, parameter application into shared volatile state.
- **Core 1** (`setup1()`/`loop1()`): renders `elements::Part::Process()` in `kMaxBlockSize = 16` sample blocks, converts to 16-bit stereo, pushes to I2S DMA. Blocked writes pace the loop at exactly 32 kHz. Waits on a `audio_ready` flag so it never renders an uninitialized `Part`.
- Sample rate **32000 Hz** (native LUT tuning in the port + CPU headroom; PCM5102A supports it).
- Reverb tank: static `uint16_t reverb_buffer[32768]` (64 KB — verified: `FxEngine<32768, FORMAT_16_BIT>` in `ELEMENTS/src/elements/dsp/fx/reverb.h:164`).
- CPU 250 MHz, `-O3`.
- Shared state written by core 0, read by core 1: aligned 32-bit float/bool writes are atomic on ARMv8-M — same pattern the existing Scarp sketches already rely on.

## Wiring (user does this; T2 needs the DAC, T5 needs the USB-A socket)

**PCM5102A breakout → RP2350 nano:**
- `BCK` → GP6
- `LCK/WS` → GP7 (= BCK+1, required by arduino-pico I2S)
- `DIN` → GP8
- `SCK/MCLK` → GND (internal PLL)
- `XSMT` → 3V3 (unmute; jumper H3)
- `FLT` (H1), `DEMP` (H2), `FMT` (H4) → GND (I2S format, normal filter — usually pre-set on breakouts)
- `VIN` → 3V3, `GND` → GND

**USB-A breakout (host) → RP2350 nano:**
- `VBUS` → 5V pin
- `D+` → GP14, `D-` → GP15 (adjacent pair, D- = D+ + 1, required by PIO-USB)
- `GND` → GND, shield → GND

## Task 2 — I2S + PCM5102A bring-up

**Files:** `elements-rp2350/src/main.cpp` (replaced).

Use the API facts recorded in T1's ledger note. Proven pattern from MarvelousMI; adapt calls to the installed header if signatures differ.

```cpp
#include <Arduino.h>
#include <I2S.h>

static const uint32_t kSampleRate = 32000;
static const uint32_t kPinBCLK = 6;   // LRCK follows on GP7
static const uint32_t kPinDOUT = 8;

I2S i2s(OUTPUT, kPinBCLK, kPinDOUT);

void setup() {
  Serial.begin(115200);
  i2s.setBitsPerSample(16);
  i2s.setBuffers(8, 16);          // 8 buffers x 16 words = 128 stereo frames (~4 ms)
  i2s.setFrequency(kSampleRate);
  i2s.begin();
  Serial.println("I2S up");
}

void loop() {
  // 220 Hz sine, 16-bit, stereo via the API chosen in T1
  static float phase = 0.0f;
  static const float dt = 2.0f * PI * 220.0f / (float)kSampleRate;
  for (int i = 0; i < 32; ++i) {
    int16_t s = (int16_t)(sinf(phase) * 8000.0f);
    phase += dt;
    if (phase > 2.0f * PI) phase -= 2.0f * PI;
    // Stereo write — use whichever form T1 confirmed:
    // i2s.write16(s, s);           // if the 2-arg form exists
    i2s.write(s); i2s.write(s);   // proven MarvelousMI form
  }
}
```

**Steps:**
1. User wires PCM5102A (see Wiring).
2. Flash, listen on headphones/amp.
3. If silent: scope/measure with a logic probe is not available — instead check `Serial` output, verify `i2s.begin()` returns true, and double-check XSMT is high (most common cause) and LCK is on BCLK+1.

**Acceptance:** audible clean 220 Hz tone at proper pitch (verify with a tuner app: ±1 Hz at 220 Hz confirms the 32 kHz clock).

**Commit:** `[Add] I2S 32kHz sine bring-up for PCM5102A`

## Task 3 — Elements engine integration (core 1 render)

**Files:** `elements-rp2350/src/main.cpp` (replaced).

```cpp
#include <Arduino.h>
#include <I2S.h>

#include <STMLIB.h>
#include <ELEMENTS.h>

#include "elements/dsp/dsp.h"
#include "elements/dsp/part.h"

// Firmware-side definitions of the Dsp statics (declared in dsp.h, defined nowhere).
float elements::Dsp::kSampleRate = 32000.0f;
float elements::Dsp::kSrFactor = 1.0f;
float elements::Dsp::kIntervalCorrection = 0.0f;

static const uint32_t kSampleRate = 32000;
static const size_t kBlockSize = elements::kMaxBlockSize;

static const uint32_t kPinBCLK = 6;
static const uint32_t kPinDOUT = 8;
I2S i2s(OUTPUT, kPinBCLK, kPinDOUT);

// --- engine ---
static uint16_t reverb_buffer[32768];   // 64 KB, verified FxEngine<32768>
static elements::Part part;
static elements::Patch* patch;
static elements::PerformanceState perf_state;

static float blow_in[kBlockSize];
static float strike_in[kBlockSize];
static float main_out[kBlockSize];
static float aux_out[kBlockSize];

// --- shared MIDI state (core0 writes, core1 reads) ---
static volatile float shared_note = 48.0f;
static volatile float shared_modulation = 0.0f;
static volatile float shared_strength = 0.8f;
static volatile bool shared_gate = false;

static volatile bool audio_ready = false;

// --- perf telemetry (core1 writes, core0 prints) ---
static volatile uint32_t proc_us_max = 0;

static void initEngine() {
  elements::Dsp::setSr(kSampleRate);

  memset(reverb_buffer, 0, sizeof(reverb_buffer));
  memset(blow_in, 0, sizeof(blow_in));
  memset(strike_in, 0, sizeof(strike_in));

  part.Init(reverb_buffer);
  uint32_t seed = 0x1fff7a10;
  part.Seed(&seed, 3);
  part.set_easter_egg(false);
  part.set_resonator_model(elements::RESONATOR_MODEL_STRING);

  patch = part.mutable_patch();
  // sensible default: strike/mallet voice
  patch->exciter_envelope_shape = 0.1f;
  patch->exciter_bow_level = 0.0f;
  patch->exciter_blow_level = 0.0f;
  patch->exciter_strike_level = 0.8f;
  patch->exciter_blow_meta = 0.5f;
  patch->exciter_strike_meta = 0.5f;
  patch->exciter_bow_timbre = 0.5f;
  patch->exciter_blow_timbre = 0.5f;
  patch->exciter_strike_timbre = 0.5f;
  patch->exciter_signature = 0.0f;
  patch->resonator_geometry = 0.25f;
  patch->resonator_brightness = 0.4f;
  patch->resonator_damping = 0.7f;
  patch->resonator_position = 0.3f;
  patch->space = 0.4f;
}

// ================= core 1: audio =================
void setup1() {
  while (!audio_ready) { delay(1); }
}

void loop1() {
  perf_state.gate = shared_gate;
  perf_state.note = shared_note;
  perf_state.strength = shared_strength;
  perf_state.modulation = shared_modulation;

  uint32_t t0 = time_us_32();
  part.Process(perf_state, blow_in, strike_in, main_out, aux_out, kBlockSize);
  uint32_t dt = time_us_32() - t0;
  if (dt > proc_us_max) proc_us_max = dt;

  for (size_t i = 0; i < kBlockSize; ++i) {
    int16_t l = stmlib::Clip16(static_cast<int32_t>(main_out[i] * 32768.0f));
    int16_t r = stmlib::Clip16(static_cast<int32_t>(aux_out[i] * 32768.0f));
    i2s.write(l);
    i2s.write(r);
  }
}

// ================= core 0: control =================
void setup() {
  Serial.begin(115200);
  initEngine();
  i2s.setBitsPerSample(16);
  i2s.setBuffers(8, 16);
  i2s.setFrequency(kSampleRate);
  i2s.begin();
  audio_ready = true;
  Serial.println("Elements engine up (auto-trigger test)");
}

void loop() {
  // bring-up test: strike every 1.5 s, gate held 300 ms
  static uint32_t last_trigger = 0;
  static uint32_t last_report = 0;
  static uint8_t step = 0;
  uint32_t now = millis();

  if (now - last_trigger > 1500) {
    last_trigger = now;
    shared_note = 36.0f + (step++ % 12);
    shared_strength = 0.9f;
    shared_gate = true;
  }
  if (now - last_trigger > 300) {
    shared_gate = false;
  }
  if (now - last_report > 2000) {
    last_report = now;
    Serial.printf("max Process: %u us (budget %u us)\n", proc_us_max, (unsigned)(1000000UL / kSampleRate * kBlockSize));
    proc_us_max = 0;
  }
}
```

**Acceptance:** audible Elements voice (strike → resonator ping) stepping through notes; reported `Process` time comfortably under the 500 µs/block budget (16 samples @ 32 kHz); no glitches when `Serial` prints run.

**Commit:** `[Add] Elements engine render on core1 at 32kHz via I2S`

## Task 4 — USB MIDI device (PC/DAW)

**Files:** `elements-rp2350/src/main.cpp` (extended), `elements-rp2350/src/midi.h` (new: shared parser + state).

**Step 0 — investigation (mandatory):** read the installed `Adafruit_USBD_MIDI.h` under `~/.platformio/packages/` (or the core's bundled library dir) and note the read API: `readPacket()` vs Stream `available()/read()`, and `begin()`. Mirror the installed API; the sketch below shows the `readPacket` form — adjust if the header differs.

**`midi.h`:**

```cpp
#pragma once
#include <ELEMENTS.h>

// shared MIDI state (core0 writes, core1 reads)
extern volatile float shared_note;
extern volatile float shared_modulation;
extern volatile float shared_strength;
extern volatile bool  shared_gate;
extern elements::Part part;

static int16_t base_note = 48;

inline void midiNoteOn(uint8_t note, uint8_t vel) {
  base_note = note;
  shared_note = (float)note;
  shared_strength = 0.4f + 0.6f * ((float)vel / 127.0f);
  shared_gate = true;
}

inline void midiNoteOff(uint8_t note) {
  if ((int16_t)note == base_note) shared_gate = false;
}

inline void midiPitchBend(int16_t bend14) {  // -8192..8191
  shared_note = (float)base_note + (float)bend14 * (2.0f / 8192.0f);
}

inline void midiControlChange(uint8_t cc, uint8_t val) {
  const float v = (float)val / 127.0f;
  elements::Patch* p = part.mutable_patch();
  switch (cc) {
    case 1:  shared_modulation = v; break;
    case 11: shared_strength = v; break;
    case 14: p->exciter_envelope_shape = v; break;
    case 15: p->exciter_bow_level = v; break;
    case 16: p->exciter_bow_timbre = v; break;
    case 17: p->exciter_blow_level = v; break;
    case 18: p->exciter_blow_meta = v; break;
    case 19: p->exciter_blow_timbre = v; break;
    case 20: p->exciter_strike_level = v; break;
    case 21: p->exciter_strike_meta = v; break;
    case 22: p->exciter_strike_timbre = v; break;
    case 23: p->resonator_geometry = v; break;
    case 24: p->resonator_brightness = v; break;
    case 25: p->resonator_damping = v; break;
    case 26: p->resonator_position = v; break;
    case 27: p->space = v; break;
    case 28: p->resonator_modulation_frequency = v; break;
    default: break;
  }
}

// USB-MIDI event packet (4 bytes) -> channel voice messages.
// CIN 0x8..0xE map directly onto the MIDI status nibble (single cable).
inline void midiHandleEventPacket(const uint8_t* pkt) {
  uint8_t cin = pkt[0] & 0x0F;
  if (cin < 0x8 || cin > 0xE) return;
  uint8_t status = (uint8_t)(cin << 4);
  switch (cin) {
    case 0x9: if (pkt[2]) midiNoteOn(pkt[1], pkt[2]); else midiNoteOff(pkt[1]); break;
    case 0x8: midiNoteOff(pkt[1]); break;
    case 0xB: midiControlChange(pkt[1], pkt[2]); break;
    case 0xE: midiPitchBend((int16_t)(((pkt[2] & 0x7F) << 7) | (pkt[1] & 0x7F)) - 8192); break;
    default: break;
  }
  (void)status;
}
```

Note: `case 28` maps modulation depth (`resonator_modulation_frequency`) for now; the resonator model selector moves to a CC in T6 once the `set_resonator_model` race with `Process` is checked (model change reallocates voice state — call it from core 1's control gate or verify thread safety in `part.cc` before exposing it).

**`main.cpp` additions (core 0):**

## Task 5 — USB host MIDI via PIO-USB (controller in USB-A socket)

**Files:** `elements-rp2350/src/main.cpp` (extended).

**Step 0 — investigation (mandatory):** list the installed Adafruit TinyUSB library's host examples (`find ~/.platformio -path '*TinyUSB*' -name '*.ino' -path '*Host*'`) and read `midi_host.h` from the bundled TinyUSB (`class/midi/host/midi_host.h`) to confirm: `tuh_midi_mount_cb/umount_cb` callback names, the read API (`tuh_midi_read(dev_addr, buf, size)` unpacking to raw MIDI bytes vs packet API), and mount/status query functions. Mirror the installed API.

**Pattern (adapt to findings):**

```cpp
#include "pio_usb.h"

Adafruit_USBH_Host USBHost;

// in setup(), after device init:
pio_usb_configuration_t pio_cfg = PIO_USB_DEFAULT_CONFIG;
pio_cfg.pin_dp = 14;                 // D+ GP14, D- GP15
USBHost.configure_pio_usb(1, &pio_cfg);
USBHost.begin(1);

// in loop():
USBHost.task();

// host callbacks (mirror names from installed midi_host.h):
void tuh_midi_mount_cb(uint8_t dev_addr) {
  Serial.printf("MIDI host device mounted, addr %u\n", dev_addr);
}

// raw-byte form if tuh_midi_read unpacks to a MIDI byte stream:
static uint8_t run_status = 0;
void pollHostMidi() {
  uint8_t buf[64];
  for (uint8_t addr = 1; addr < 8; ++addr) {
    if (!tuh_midi_mounted(addr)) continue;
    uint32_t n = tuh_midi_read(addr, buf, sizeof(buf));
    for (uint32_t i = 0; i < n; ++i) midiHandleByte(buf[i]);   // add a classic byte-parser in midi.h
  }
}
```

If the installed `tuh_midi_*` only exposes event packets, route them through `midiHandleEventPacket` instead. Add `midiHandleByte()` to `midi.h` (status-byte state machine with running status; ~30 lines) so both transports share one entry point.

**Watch out:**
- PIO resources: PIO-USB needs 2 SMs in one PIO block; the I2S library also claims PIO SMs. RP2350 has PIO0/1/2 — if allocation collides at boot (serial log shows PIO claim failure), force I2S onto a specific PIO via its `setPIO()`-style API if present, or move I2S pins.
- Power: the host socket must supply 5 V on VBUS from the board's 5V pin. If the controller is bus-powered and the board is powered from the PC USB-C, current is fine for small controllers.
- Some controllers need `USBHost.task()` serviced frequently — it is on core 0's loop, which is not DSP-loaded; fine.

**Acceptance:** hardware MIDI controller plugged into the USB-A socket plays the synth; USB-C still enumerates as MIDI device to the PC at the same time.

**Commit:** `[Add] USB host MIDI via PIO-USB`

## Task 6 — Hardening + documentation

1. **Note stack:** last-note priority with stack (push on note-on, pop on note-off, gate off only when empty) — replace the single `base_note` logic.
2. **Resonator model CC:** verify `set_resonator_model()` thread-safety against `Process()` (read `part.cc`/`voice.cc`); if unsafe, apply it from core 1 between blocks via a pending-model flag. Map CC 28 → model 0/1/2.
3. **Stuck-gate recovery:** if gate is on for > 30 s with no note-off, force off (defensive; keeps reverb from howling).
4. **Startup defaults:** send CC defaults into the patch at boot (the init values from T3), so a controller can reset by re-sending CCs; optionally respond to MIDI Program Change with a small bank of 4 factory-ish patches.
5. **Remove the auto-trigger test** once MIDI paths are confirmed.
6. **Diagnostics:** periodic serial report of max Process time, I2S write stall count (wrap `i2s.write` and count blocking > threshold), host mount/unmount events.
7. **README** (`elements-rp2350/README.md`): wiring tables, CC map, upload procedure (as verified in T1), PIO-USB caveats, how to re-sync submodules.
8. **Soak test:** run ≥ 30 min with sequenced notes from the host controller; AC: no crash, no audio drop, max Process time stable.

**Commit:** `[Add] note stack, model CC, diagnostics, README` (split as needed)
