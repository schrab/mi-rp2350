# Plaits RP2350 — port plan (all 98 Plaits-Lab engines, one firmware)

Source: **lylepmills/eurorack** (Rubato "Plaits Lab" fork of pichenettes eurorack)
— all models stereo-converted, 98-engine catalog (63 MI incl. Braids-derived
engine2 set, 22 Rubato Lab, 13 community; 2 catalogued as "retired" but still
functional). Cloned at `EURORACK-STEREO/` (submodule).

Key fork facts (survey 2026-11-02, HEAD `83f86ae`):

- `plaits/dsp/voice.h` — `Voice::Init(stmlib::BufferAllocator*)`, engines are
  direct Voice members via `PLAITS_ENGINE_MEMBERS`; workspace is `Free()`d per
  engine → pool must cover the **largest** engine only (measured max 16.4 KB:
  ParticleEngine uint16_t[8192]).
- `Frame { short out; short aux }`, native **48 kHz**, `kMaxBlockSize = 24`,
  `kBlockSize = 12`. Stereo = `patch.aux_output_option == 1` +
  `engine->stereo_capable()` → OUT=left, AUX=right, shared limiter
  (`voice.cc:500-501`, `voice.cc:904-935`). All engines compile-time
  stereo-on by default (`dsp/engine/stereo_config.h`).
- **32-slot ceiling** (`build_config.h:36` `#error`) is enforced only by
  `uint32_t` speech/chiptune masks used at **8 sites, all in `voice.cc`**
  (`1u << engine_index`). No enum; engine = registry index
  (`engine_quantizer_.Process` → `EngineRegistry`).
- `user_data.h` (in voice.cc's include graph) reads STM32 flash
  (`0x08007000`); `LoadUserData(NULL)` is a documented no-op path. With
  `PLAITS_HAS_USER_DATA_BANK=1` the DX7 banks come from `syx_bank_0/1/2` in
  resources.cc instead of flash.
- Fork's own on-target sweeps (STM32F373 @72 MHz, 12-sample blocks): worst
  engine ≈ 0.98 of a 1500-cycle/sample budget → ≈ **30% of our 500 µs budget**
  at 240 MHz/48 kHz. No FFT anywhere; `double` used exactly once
  (struck_drum_engine.cc:233, floatable). Zero new/malloc outside the
  allocator.
- Fork stmlib submodule is EMPTY; plaits uses exactly 14 stmlib **headers**,
  all present and API-compatible in poetaster's `STMLIB/` submodule → reuse it.

## Architecture decisions

| Decision | Choice | Why |
|---|---|---|
| Engine set | **All 98 in one build** (catalog order 0-97) | User requirement; RAM/flash/cpu all fit (see risks) |
| 98-slot support | `-DPLAITS_ENGINE_COUNT=98` (project flags) + patch: build_config ceiling 32→98, `voice.cc` mask sites → `uint64_t`/`1ULL`, replacement `dsp/engine_config.h` with `PLAITS_ENGINE_MEMBERS`/`PLAITS_REGISTER_ENGINES` for all 98 | The ceiling is not structural — masks are the only slot-width coupling |
| Sample rate | I2S **48 kHz**, block = `plaits::kMaxBlockSize` (24), budget 500 µs (multiply-first) | Rate is baked into every engine's constants; zero code risk |
| Tuning shim | `-DPLAITS_CORRECTED_SAMPLE_RATE=48000.0f` → `kCorrectedPitchOffset` computed = 0 | We run true 48 kHz, not the module's 47872.34 |
| Stereo | `patch.aux_output_option = 1` default; `Frame.out/aux` → `i2s.write16(l, r)` | PCM5102A is stereo; the whole point of this fork |
| Workspace | `static uint32_t pool[8192]` (32 KB) + `stmlib::BufferAllocator` | Largest engine 16.4 KB + margin |
| DX7 banks | `PLAITS_HAS_USER_DATA_BANK=1`; `user_data.h` stubbed to the documented NULL path | Banks come from resources.cc; no STM32 flash |
| Lib integration | mode `cc`, include root = lib/plaits, copy nests as `lib/plaits/plaits/…` (fork includes are `"plaits/dsp/…"`-prefixed) | Matches clouds' `cc` pattern |
| Prune on sync | bootloader/ drivers/ test/ tools/ hardware_design/ resources/syx + root UI/firmware files (plaits.cc, ui.*, settings.*, user_data_receiver.*, ~15 diagnostic headers, makefiles) | Only `resources.*`, `dsp/`, `build_config.h`, `section_marks.h`, `user_data.h`(+`user_data_region.h`) compile |
| STMLIB | reuse poetaster submodule via existing `inc` mode | 14 headers verified compatible |
| Optimisation | library.json `flags: ["-O3"]` (core appends `-Os` after project flags); project flags carry the `-D`s | Established law |
| Template | `clouds-rp2350/src/*` (mode cc, pending slots, corrected budget math, report fields) minus exciter; LED via `led_brightness_lut.h` pair | Per PORTING-HIGHLIGHTS §10 |

## MIDI mapping (draft, finalize in T2 from plaits.cc contract)

Note stack (last-note priority) → `patch.note` (convention read from
`plaits.cc` — copy the original firmware's per-block fill exactly), velocity →
accent, note-on → `modulations.trigger` pulse. CCs: 14 TIMBRE, 15 MORPH, 16
HARMONICS, 17 MACRO/TWIST (`EngineParameters.macro`), 18 LPG COLOR, 19 DECAY,
20 FM AMOUNT, 21 TIMBRE MOD AMT, 22 MORPH MOD AMT, 23 **ENGINE 0-97**, 24 AUX
OPTION (0 aux-model / 1 stereo / 2 subosc), 25 LEVEL. Bend standard.

## Risks / fallbacks

- **Voice object with 98 engine members** could be fat (SixOpEngine ~5.4 KB ×3
  registrations = 16 KB alone). Measure `sizeof` via nm/map at T1; fallback:
  drop the 2 retired engines, then SixOp×3→1, then single-recipe subsets.
- **Flash** with 98 -O3 engines: fine on 4 MB, but record %.
- **Tuning**: if I2S bitclock isn't exactly 48 kHz, retune via
  `PLAITS_CORRECTED_SAMPLE_RATE` (verify against a reference tuner in T5).
- **`PLAITS_ENGINE_ROWS`/`PLAITS_BANK_SIZES`** defaults assume 24 —
  UI-only (static_asserts live in excluded `ui.cc`); grep compiled TUs to
  confirm no reference, else define for 98.
- Patch discipline: alphabetical apply order, disjoint file sets per patch,
  `--fuzz=0`, regenerate from post-previous-patch state (PORTING-HIGHLIGHTS §2).
